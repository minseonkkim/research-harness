# 경쟁 앱 조사: 아이 사진 정리·앨범 앱

- 관점: 이어북(연간 포토북) 편집기의 사진 선택 단계 기획
- 기준일: 2026-11-25
- 대상: Bebememo (베베메모), 쑥쑥찰칵 (Babyfolio)

> 표기: ✓ 독립 검증 확인 · ✎ 검증에서 수정 · ? 검증 불가

## 요약

- 조사한 두 앱 모두 이어북 편집기 안에서 쓰는 "AI 베스트컷 자동 선별" 기능은 확인되지 않았다. 사진 선택 부담은 **편집기에 들어가기 전 단계**에서 줄인다.
- **Bebememo**는 AI가 갤러리에서 아기 사진을 찾아 원탭으로 업로드하고 월령별로 자동 그룹화한다. 이어북은 이렇게 이미 걸러진 사진 풀을 입력으로 받는 구조로 보인다(추론). 이어북 판매($55부터)와 QR로 영상·음성을 연결하는 기능은 제3자 자료 1건에만 근거한다(미확인).
- **쑥쑥찰칵**은 1년 동안 쌓인 큐레이션 신호(즐겨찾기 폴더, 가족 좋아요, 태그, 개월·아이별 분류)로 후보를 좁히고, 그 안에서 사용자가 직접 고른다. 연간 달력에는 "자동 채우기 + 얼굴 기준 배치"를 2026-11 Android 업데이트로 넣었다.
- 두 앱 공통으로, 선택 대상은 앱에 업로드된 사진뿐이다. 화질 경고, 수동 교체, 얼굴 위치 수동 조정이 남아 있는 마찰 요인이다(쑥쑥찰칵 기준). 편집기 실제 화면과 장수 제한은 두 앱 모두 확인하지 못했다(미확인).

## 관점별 기능 패턴

**1. 업로드 단계에서 미리 선별하기**
- Bebememo: 아기 정보를 등록하면 AI가 기기 갤러리에서 아기 사진·영상을 찾아 후보로 보여 주고, 사용자는 확인 후 원탭으로 업로드한다. 이 과정이 온보딩 때 실행된다.
- 쑥쑥찰칵: 스토어 설명에 "AI로 사진을 자동으로 찾아드려요"라는 문구가 있다. 포토북 선택은 서버에 올라간 "쑥쑥찰칵 앨범"에서만 한다.
- 한계: Bebememo의 AI가 사진을 놓친다는 지적이 있다(미확인, 자동 생성된 제3자 요약). 쑥쑥찰칵에서는 업로드하지 않은 사진이 후보에서 빠진다. 한그루 알림장 연동도 2026-09-01에 종료됐다.

**2. 시간축으로 자동 정리해 후보 좁히기**
- Bebememo: 생일 기준 월령(예: "8M old")과 날짜로 자동 그룹화하고, 타임라인·캘린더 뷰를 제공한다.
- 쑥쑥찰칵: 촬영일, 생후 D+일, 개월, 아이별로 정리한다. 2026-09 개편으로 아이별 필터가 추가됐다.

**3. 1년 동안 쌓은 큐레이션 신호로 필터링하기**
- 쑥쑥찰칵: 즐겨찾기 폴더를 골라 그 폴더 사진만 불러올 수 있다(iOS 7.7.03, 2026-10-26). 정렬은 날짜순·즐겨찾기순, 최신순·오래된순 중에서 고른다. "좋아요한 사진만 모아보기"로 가족 반응도 선택 신호가 된다. 태그 필터도 있다.
- Bebememo: 가족 좋아요·댓글 기능은 있지만, 이것을 이어북 선택에 쓰는지는 확인되지 않았다(미확인).

**4. 기록 데이터 자동 연결하기**
- 쑥쑥찰칵: "하루한장 포토북"은 페이지 글 칸에 그날 일기를 자동으로 불러온다(iOS 7.7.06, 2026-11-06).
- Bebememo: 인쇄 이어북에 QR코드를 넣어 앱 속 영상·음성으로 연결한다(미확인, 날짜 미상의 제3자 UI 분석 1건).

**5. 자동 배치와 얼굴 인식**
- 쑥쑥찰칵: 연간 달력을 사진으로 자동으로 채우고, 얼굴이 잘 보이게 배치한다(Android, 2026-11-19. iOS 반영 여부는 미확인). 디지털 액자의 "AI 추천"은 최근·과거 사진을 비율에 맞춰 랜덤으로 고르는 수준이다. 포토북에 적용되는지는 미확인이다.
- Bebememo: 해당 기능을 확인하지 못했다(미확인).

**6. 품질 검증과 수동 보정**
- 쑥쑥찰칵: 저·중해상도 사진에 교체 권장 알림을 띄우고 300dpi 이상을 권장한다. 인화 시 얼굴이 잘리지 않게 사용자가 프레임을 직접 조정해야 한다. 인화는 최소 35장이고, 달력은 임시저장(최대 20개)을 지원한다.
- Bebememo: 확인된 자료가 없다(미확인).

**7. 수익 구조와 결합**
- 두 앱 모두 구독과 인쇄물 판매를 따로 운영한다. 쑥쑥찰칵은 사진 1,000장 이상 올린 사용자에게 매월 무료 인화를 준다. 업로드 양이 많을수록 선택 풀도 커지는 구조다. Bebememo의 Print Store 상품 구성(Yearbook, 연간 액자, 폰케이스, 탁상달력)은 제3자 출처다(미확인).

## 기획 시사점

**근거가 있는 제안**
- **입력 풀을 미리 정제한다.** 편집기에 1년치 전체를 보여 주지 말고, 월령·개월별로 그룹화된 아이 사진 풀을 입력으로 쓴다. 근거: 두 앱 모두 월령·개월 자동 정리를 기본으로 한다.
- **연중 큐레이션 신호를 필터로 노출한다.** 사진 선택 화면에 즐겨찾기 폴더, 가족 좋아요, 태그, 아이별 필터를 두고 정렬 옵션도 함께 준다. 근거: 쑥쑥찰칵 iOS 7.7.03, 2026-09 가족 앨범 개편.
- **가족 반응을 선별 신호로 쓴다.** 조부모 등 가족이 누른 좋아요를 "후보 우선순위"로 활용한다. 근거: 쑥쑥찰칵의 "좋아요한 사진만 모아보기".
- **자동 채우기와 얼굴 기준 배치를 기본값으로 둔다.** 근거: 쑥쑥찰칵이 연간 달력에 이미 도입했다(Android 2026-11). 얼굴 잘림을 사용자가 수동으로 조정하는 마찰을 없애는 방향이다.
- **해상도 검증을 선택 단계에 넣는다.** 저해상도 사진은 경고하고 교체 후보를 제시한다. 근거: 쑥쑥찰칵의 300dpi 권장과 교체 권장 알림. 원본이 아닌 "일반 화질" 저장이 불만 요인이므로, 인쇄용 원본을 확보하는 경로도 함께 검토한다.
- **기록 데이터를 자동으로 결합한다.** 선택한 사진의 날짜에 맞는 일기·마일스톤을 페이지 텍스트로 자동으로 불러온다. 근거: 쑥쑥찰칵 하루한장 포토북.
- **임시저장을 지원한다.** 근거: 쑥쑥찰칵 달력의 임시저장(최대 20개).

**추론에 기반한 제안**
- **품질 기반 자동 선별을 차별화 포인트로 삼는다(추론).** 흔들림·중복 제거, 베스트컷 추천은 두 앱 모두 확인되지 않았다. 따라서 "월별 N장 자동 추천 → 사용자 교체" 흐름이 빈 영역일 수 있다.
- **업로드되지 않은 사진도 후보로 끌어온다(추론).** 서버 업로드분만 후보가 되는 한계와 AI 탐지 누락 지적(미확인)이 있으므로, 편집기에서 갤러리를 다시 스캔하거나 직접 추가하는 경로를 두는 것이 좋다.
- **QR로 영상·음성을 연결하는 기능을 검토한다(추론).** 인쇄물의 한계를 보완하는 요소로 참고할 만하다. 다만 Bebememo 사례 자체는 제3자 자료 1건에만 근거한다(미확인).
- **교체 UX를 최소 터치로 설계한다(추론).** 자동 배치 이후 사용자가 하는 작업은 주로 "특정 칸의 사진 교체"일 것이다. 같은 월·같은 이벤트 안에서 대체 후보를 바로 보여 주는 방식이 적합하다.

**추가로 확인할 것**
- 두 앱 이어북·포토북 편집기의 실제 화면을 캡처해야 한다. 자동 선별 여부, 최소·최대 장수, 페이지 수, 교체 방식이 미확인이다.
- Bebememo 한국판에서 이어북을 제공하는지 확인해야 한다(미확인).
- Bebememo와 TimeHut의 관계가 미확인이므로, TimeHut의 이어북 기능도 함께 볼 필요가 있다.
